# Schloss Erlangen 3D

**Live:** https://bies93.github.io/SchlossER/

## Was ist das?
Ein begehbares Schloss Erlangen samt Schlossgarten im Browser, gebaut mit Three.js. Es ist komplett nutzlos aber halbwegs maßstabsgetreu, hat dafür paar seltsame Geheimnisse, die man erst finden muss. 
Ähnlichkeiten zu realen Personen sind zufällig.


## Steuerung
- **WASD**: gehen · **Umschalt**: rennen · **Leertaste**: springen
- **Maus**: umsehen · **E**: interagieren / aufheben
- **Mausrad**: Waffe wechseln / wegstecken · **Rechtsklick**: zielen · **Linksklick**: schießen
- **Esc**: Pause · **M**: Ton
- **Touch**: links gehen, rechts umsehen, Buttons für Waffe, Schießen, Sprung
